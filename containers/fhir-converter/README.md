## DIBBs FHIR Converter

The DIBBs FHIR Converter service offers a REST API for converting data from formats such as eCR and ELR to FHIR. For more information on how to use the FHIR Converter see the [README in the DIBBs FHIR Converter repo.](https://github.com/CDCgov/dibbs-FHIR-Converter/blob/main/src/Dibbs.FhirConverterApi/README.md)
