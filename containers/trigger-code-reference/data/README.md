# Seeding the TES SQLite Database

Running the `tes_data.py` script will create and populate the `tes.db` SQLite database with data, which will then be used by the TCRS.

## Running the script

1. Navigate into the `app` directory - `cd app`
2. Run the `tes_data.py` script directly - `python tes_data.py`
3. You should see the output from the script and a newly created `tes.db` database file in the `/data` directory
